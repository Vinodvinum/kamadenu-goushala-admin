## 📋 Overview

**Kamadenu Goushala Admin** is the backend management interface for the [Kamadenu Goushala](https://kamadenu-goushalaa.vercel.app/) platform. It allows administrators to manage cow shelter records, track seva activities, handle donation workflows, and oversee platform content.

---

## ✨ Features

- 🐄 Cow inventory and health record management
- 🔖 Seva activity tracking and scheduling
- 💸 Donation management and reporting
- 👤 Volunteer and contributor management
- 📄 Content management for the public-facing website
- 📊 Admin analytics and dashboard

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|

| Firebase / Firestore | Real-time database and auth |
